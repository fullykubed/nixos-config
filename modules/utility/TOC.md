# Table of Contents — modules/utility/

- **amd-cpu.nix** - Loads the AMD KVM kernel module for AMD processor support.
- **amd-gpu.nix** - Enables AMD GPU drivers with Vulkan support and the CoreCtrl overclocking tool.
- **brother-scanner.nix** - Configures Brother network scanner (MFC-L2750DW) with brscan5 drivers and SANE integration.
- **debug.nix** - Comprehensive debug module that dumps system state, hardware info, and NixOS configuration details for troubleshooting.
- **disable-wakeup-triggers.nix** - Systemd service that disables ACPI wakeup triggers to prevent unwanted wake-from-sleep events.
- **intel-cpu.nix** - Loads the Intel KVM kernel module for Intel processor support.
