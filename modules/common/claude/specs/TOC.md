# specs/

Shared specification files and JSON schemas referenced by skills to avoid duplication.

- `prd-spec.md` — Specification for PRD format, structure, directory layout, and task/research YAML format.
- `task-spec.md` — Specification for task definitions including status fields, dependencies, specs, and serialization.
- `log-spec.md` — Specification for conversation logging format and metadata structure in PRD workflows.
- `tasks.schema.json` — JSON Schema validating task YAML structure; enforced by PRD skill hooks.
- `research.schema.json` — JSON Schema validating research question YAML structure; enforced by PRD skill hooks.
