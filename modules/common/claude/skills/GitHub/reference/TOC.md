# reference/

Reference documentation for the GitHub skill.

- `gh-commands.md` — Reference guide for gh CLI commands covering issue creation, gist management, and repository operations.
- `bug-report-template.md` — Default template for bug reports when the target repository does not provide its own.
- `feature-request-template.md` — Default template for feature requests when the target repository does not provide its own.
- `pii-stripping.md` — Instructions for scanning and redacting personally identifiable information from issue reports and gist files.
