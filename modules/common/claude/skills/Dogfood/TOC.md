# Dogfood/

Web application testing skill for systematically exploring and finding bugs, UX issues, and other problems.

- `SKILL.md` -- Skill definition with 6-step dogfood workflow (initialize, authenticate, orient, explore, document, wrap up) and guidance on evidence capture.
- `default.nix` -- Nix home-manager integration; deploys skill files to `~/.claude/skills/Dogfood/`.
- `reference/issue-taxonomy.md` -- Classification of bug types by category (functional, UX, visual, performance, accessibility, content, console) with severity levels and exploration checklist.
