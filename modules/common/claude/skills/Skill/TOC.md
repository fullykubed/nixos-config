# Skill/

Meta-skill for creating and managing Claude Code skills, workflows, and references.

- `SKILL.md` — Skill definition with two workflows (CreateSkill, UpdateSkill) for skill lifecycle management.
- `default.nix` — Nix derivation building utility scripts and exporting the validation hook.
- `hooks/` — Post-edit validation hook for SKILL.md format compliance.
- `reference/` — Specifications for skill structure, workflow format, and available CLI tools.
- `scripts/` — CLI tools for listing and inspecting skills.
- `workflows/` — Step-by-step procedures for creating and updating skills.
