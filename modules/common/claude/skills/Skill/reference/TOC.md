# reference/

Specifications for skill structure, workflow format, and available CLI tools.

- `skill-spec.md` — Complete skill specification: directory structure, SKILL.md format, workflow routing, invocation control, and Nix integration.
- `workflow-spec.md` — Workflow specification: file format, required sections, conventions, and variable placeholders.
- `cli-tools.md` — CLI tools for skill management: list-skills, skill-info, validate-skill.
