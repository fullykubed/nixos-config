# workflows/

Step-by-step procedures for PRD lifecycle management.

- `CreatePRD.md` — Create a new PRD: gather objective, identify motivation, define architecture, list constraints, and find relevant files.
- `PlanPRD.md` — Analyze and plan an existing PRD: research unknowns, refine architecture, generate ordered task list with dependencies.
- `WorkPRD.md` — Implement PRD tasks: execute in order, track status, run tests, handle failures, and mark complete.
