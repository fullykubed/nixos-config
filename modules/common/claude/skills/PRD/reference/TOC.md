# reference/

Specification docs for PRD format, tasks, logging, and available CLI tools.

- `prd-spec.md` — PRD file format specification: objective, motivation, architecture, constraints, and discussion sections.
- `task-spec.md` — Task definition specification: title, description, status, dependencies, and spec file references.
- `log-spec.md` — Conversation logging format and metadata structure for PRD workflows.
- `cli-tools.md` — CLI tools available in PRD workflows (list-prds, task-status, get-task, research-status, etc.).
